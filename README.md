📝 Todo List App

Простий та мінімалістичний застосунок для керування задачами (Todo List). Дозволяє додавати, видаляти та відмічати задачі як виконані.

🚀 Технології<br>
React — побудова інтерфейсу <br>
TypeScript — типізація <br>
RTK Query — робота з API та кешування даних<br>
React Hook Form — зручна робота з формами<br>
CSS Modules — модульна стилізація компонентів<br>

✨ Функціонал<br>
➕ Додавання нових задач<br>
✔️ Позначення задач як виконаних / невиконаних<br>
🗑️ Видалення задач<br>
🔄 Синхронізація з API через RTK Query<br>
🎯 Валідація форм через React Hook Form<br>

📦 Запуск проєкту<br>
npm install<br>
npm run dev<br>

або

yarn install<br>
yarn dev<br>

⚙️ Environment variables

Для роботи застосунку необхідно створити файл .env у кореневій директорії проєкту:

VITE_BASE_URL має містити адресу backend API.
